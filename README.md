# Hotel KPI Calculator

A Python script that takes your hotel's monthly data from Excel and spits out RevPAR, ADR and occupancy automatically. Built for hotel managers who are tired of doing this by hand every month.

## How to use it

1. Fill in your data in `datos_hotel.xlsx`
2. Double-click `ejecutar.bat`
3. Check `resultados_kpi.xlsx` for the results

No coding needed on your end.

## What it calculates

- Occupancy rate
- ADR (Average Daily Rate)
- RevPAR (Revenue Per Available Room)
- Monthly summary with best-performing month
